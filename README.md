# Agentic AI

This repository contains lab programs executed as part of the Agentic AI elective course in Semester 7.

## Lab Programs

| Lab | Topic |
|-----|-------|
| 1 | A Tool-Using Agent with LangChain |
| 2 | A Chatbot that Remembers, using LangGraph |
| 3 | Human-in-the-Loop: Approve Before Sending |
| 4 | Ask Questions About a PDF (RAG) |
| 5 | Self-Correcting (Adaptive) RAG |
| 6 | Two Agents: Writer & Critic (AutoGen) |
| 7 | Memory That Survives Across Sessions (SQLite) |
| 8 | A Supervisor that Delegates to a Worker |
| 9 | See Inside Your Agent with LangSmith |
| 10 | Capstone: A 3-Agent News Pipeline |

## Prerequisites

* Python 3.10 or higher
* Jupyter Notebook or Google Colab

## Setup

1. Open the required `.ipynb` file in Google Colab.
2. Run the first cell of the notebook to install the required dependencies.
3. Enter your Groq API key in the designated cell.
4. Run the remaining cells in order.
